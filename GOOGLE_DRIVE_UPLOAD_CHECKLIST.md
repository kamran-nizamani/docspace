# Google Drive upload checklist

## 1. Create the folder
Create a Google Drive folder named `Ajaia DocSpace Submission`.

## 2. Upload these items
- [ ] Source ZIP downloaded from https://github.com/kamran-nizamani/docspace (GitHub **Code → Download ZIP**).
- [ ] `README.md`
- [ ] `ARCHITECTURE.md`
- [ ] `AI_WORKFLOW.md`
- [ ] `SUBMISSION.md`
- [ ] `WALKTHROUGH_SCRIPT.md`
- [ ] `WALKTHROUGH_VIDEO.txt` after replacing the placeholder with your actual recording URL.
- [ ] Optional screenshots of the live app, only if they show real current app behavior.

## 3. Record the walkthrough
Use `WALKTHROUGH_SCRIPT.md` to record a 3–5 minute screen walkthrough. Upload it to YouTube as Unlisted, Loom, or Drive. Confirm the reviewer can open it without requesting access.

## 4. Set sharing permissions
Right-click the Drive folder → Share → General access → Anyone with the link → Viewer. Copy the folder link and test it in a private/incognito browser window.

## 5. Final assessment form
Submit:
- Live product URL: https://docspace-8m5a.vercel.app/
- GitHub repository: https://github.com/kamran-nizamani/docspace
- Google Drive folder URL: paste the link copied from Drive.
- Walkthrough video URL: paste the actual URL.
- Markdown content: copy the final contents of `SUBMISSION.md`, updating the video URL and verification status before submission.

## Important honesty checks
- Do not state the video is complete until it is recorded and uploaded.
- Do not claim a manual test passed unless you ran it.
- Demo identity switching and localStorage are not production authentication or cross-device persistence.
